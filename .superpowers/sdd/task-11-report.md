## 功能清单

### ✅ 已实现的核心功能

1. **分类过滤**
   - 顶部标签式分类导航（横向滑动）
   - 从产品模块系统动态加载分类列表
   - "全部"默认选项 + 各模块分类
   - 选中状态视觉反馈（高对比度样式）

2. **搜索功能**
   - 页面顶部搜索栏，支持实时输入
   - 接收首页传入的搜索词（通过路由参数 `?search=xxx`）
   - 本地客户端搜索过滤（标题、摘要、标签三个维度）
   - 确认搜索后自动刷新列表

3. **价格排序**
   - 三种排序选项：综合排序、价格低到高、价格高到低
   - 客户端排序（解析价格文本并排序）
   - 活跃排序按钮的高亮效果

4. **商品网格展示**
   - 两列网格布局（符合小程序移动端标准）
   - 每个商品卡片包含：
     - 商品封面图（失败后展示模块名称）
     - 商品标题（两行截断）
     - 商品价格（红色高对比度显示）
     - 商品类型标签
     - 售罄状态徽章
   - 点击卡片导航到商品详情页

5. **下拉刷新**
   - 使用 `scroll-view` 的 `refresher-enabled` 属性
   - 触发刷新时重置分页到第 1 页
   - 加载中状态反馈

6. **上拉加载更多**
   - 监听 `scrolltolower` 事件
   - 自动计算是否还有更多数据（基于 `total` 和 `products.length`）
   - 加载中状态指示器
   - "没有更多商品"终止提示

7. **加载状态指示**
   - 初始加载状态：骨架屏动画（两列四个占位符）
   - 错误状态：错误提示 + 重试按钮
   - 空状态：友好提示消息
   - 加载中文案清晰

## API 调用细节

### productApi.list() 调用
```typescript
const result = await productApi.list({
  page: number,          // 当前分页
  pageSize: 10,          // 每页商品数
  moduleCode?: string,   // 分类代码（可选）
  search?: string        // 搜索词（可选）
})

// 返回: { list: Product[], total: number, page: number, pageSize: number }
```

### productApi.modules() 调用
```typescript
const modules = await productApi.modules()
// 获取所有产品模块，用于分类导航
```

### reportProductEvent() 调用
```typescript
// 页面加载时上报展示事件
reportProductEvent({
  eventType: 'impression',
  sourceScene: 'shop_list',
  tags: searchInput.value ? [searchInput.value] : undefined,
})

// 用户点击商品时上报点击事件
reportProductEvent({
  eventType: 'click',
  productId: id,
  sourceScene: 'shop_list',
})
```

## 数据流与缓存策略

### 分页缓存
- 使用 `currentPage` 跟踪当前分页
- 首次加载和下拉刷新时重置为第 1 页
- 上拉加载更多时递增分页号
- 避免重复请求同一分页的产品

### 客户端搜索过滤
- 从 API 获取完整列表后进行本地过滤
- 搜索维度：商品标题、摘要、标签
- 支持中英文混合搜索

### 排序实现
- 使用 Vue 计算属性 `sortedProducts` 实现
- 不修改原始数据，保证数据完整性
- 价格解析：使用正则表达式提取数字（支持"¥100-200"格式）

## 路由与参数处理

### 从首页传入参数
```
/pages/shop/list?search=瑜伽&category=health
```

- `search`: 搜索词（自动解码并填充搜索框）
- `category`: 分类代码（自动选中分类）

### 导出到详情页
```
/pages/products/detail?id=123
```

## UI/UX 设计亮点

1. **骨架屏动画**：两列四个占位符，持续加载动画提升用户体验
2. **售罄徽章**：绝对定位在图片右上角，实时显示库存状态
3. **按钮反馈**：:active 伪类提供按压反馈（缩放 + 阴影）
4. **颜色系统**：
   - 主色：#333（深色文本）
   - 强调色：#e74c3c（红色价格）
   - 背景色：#f5f5f7（浅灰）
   - 排序活跃色：#e8f5e9（浅绿）
5. **排版层级**：标题 > 价格 > 类型标签，清晰的视觉层级

## 性能优化

1. **计算属性缓存**：排序通过计算属性实现，避免每次渲染都排序
2. **懒加载**：上拉加载更多实现增量加载
3. **图片优化**：使用 `mode="aspectFill"` 保证图片宽高比
4. **样式优化**：使用 SCSS 嵌套减少样式代码量

## 已知限制与未来改进

1. **搜索功能**：目前为客户端过滤，如商品库存庞大建议改为服务端搜索
2. **排序性能**：当商品数超过 1000 时建议改为服务端排序
3. **图片懒加载**：未实现图片懒加载，可考虑添加 `vue-lazyload`
4. **缓存策略**：未实现页面销毁后的数据持久化，重新进入需重新加载
