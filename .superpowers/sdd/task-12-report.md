5. **加入购物车功能**
   - 动态按钮文案：根据商品状态显示
   - 已售罄状态：按钮禁用并显示"商品已售罄"
   - 加载中状态：显示"添加中..."
   - 成功后 Toast 提示：确认商品已加入
   - 数量重置：成功后将数量重置为 1
   - 购物车更新：调用 API 后更新全局购物车状态

6. **错误处理和重试**
   - 加载失败时显示重新加载按钮
   - 添加失败时显示错误提示
   - 异常捕获和日志记录

7. **数据获取和状态管理**
   - 从 URL 参数获取商品 ID
   - 调用 `shopApi.productDetail(id)` 获取商品详情
   - 调用 `cartApi.addItem()` 添加到购物车
   - 使用 Pinia `useCartStore()` 管理全局购物车状态

## 技术实现细节

### 页面配置
- **路由参数**：通过 `id` 参数传递商品 ID
- **生命周期**：使用 `onLoad()` 在页面加载时获取商品 ID 和数据

### API 调用
```typescript
// 获取商品详情
shopApi.productDetail(productId: number): Promise<ShopProduct>

// 添加到购物车
cartApi.addItem(productId: number, quantity: number): Promise<Cart>
```

### 响应式数据
- `product`: 商品详情对象
- `loading`: 加载状态
- `loadError`: 错误标志
- `addingToCart`: 添加中状态
- `currentImageIndex`: 当前图片索引
- `quantity`: 购买数量

### 计算属性
- `priceYuan`: 将分单位的价格转换为元，保留两位小数
