## 回滚

如需回滚程序，保留新增数据库结构并切回旧版本：

```bash
ssh blisstribe-prod 'ln -sfn /opt/blisstribe/releases/20261015-product-workspace-02 /opt/blisstribe/current && systemctl restart blisstribe-api'
```

旧代码会把分类平铺显示。若要恢复测试商品原有一级分类归属，按 `subcategories-manifest.json` 的父分类及商品 ID 回迁，只处理仍属于清单中子分类的商品，再停用本批次新增子分类。保留已产生的订单历史，不通过整库恢复清理测试分类。
