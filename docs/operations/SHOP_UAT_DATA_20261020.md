## 执行与追溯

脚本：[seed-shop-uat.cjs](../../apps/api/prisma/seed-shop-uat.cjs)。默认只打印计划；`--apply` 才写入，需要显式提供数据库地址、公开 API 地址和上传目录。

```bash
node apps/api/prisma/seed-shop-uat.cjs
```

脚本按批次 SKU 编码查重，重复执行保留已有商品及测试后的库存，不重置测试进度。所有数据库创建操作在一个事务中完成。

- 执行前数据库备份：`/opt/blisstribe/backups/20261020-shop-uat-01/database.dump`。
- 创建清单：同目录 `manifest.json`，包含商品 ID、状态、场景。
- 图片：`/var/lib/blisstribe/uploads/shop-uat-20261020-*.jpg`。
- 本次只增加数据和上传图片，API 无需重启。

二级分类分组脚本：[seed-shop-subcategories.cjs](../../apps/api/prisma/seed-shop-subcategories.cjs)。默认预览，迁移完成后用 `--apply` 写入；只调整仍挂在原测试一级分类下的样例商品，不覆盖手工移至其他分类的商品，也不重置库存或售价。

二级分类执行清单：`/opt/blisstribe/backups/20261020-shop-categories-01/subcategories-manifest.json`，包含父分类、子分类和商品关联，方便按批次回迁。
