# 购买入口与操作反馈优化

日期：2026-10-15。依据：[产品设计评估](../product/PRODUCT_EXPERIENCE_REVIEW_20261015.md)。本轮实施第一批入口、状态与结果反馈优化。

## 完成内容

- 产品详情有套餐时，底部主按钮为“选择套餐”，单套餐直接打开，多套餐滚动到选项；已提交咨询不再阻塞购买入口。
- 咨询作为次操作；已有咨询进入咨询列表，未咨询可跳转需求表单提交。
- 套餐加载失败有错误与重试入口，不再静默隐藏套餐。页面再次显示时刷新产品及套餐信息。
- 咨询详情新增套餐列表，区分无需资格、等待资格和已确认资格；进入套餐页再校验实际购买条件。
- 套餐页登录后加载可购买状态与原因，提交前再次校验，避免连续点击重复跳转。
- 首页“需求评估”区域改为“服务分类”，点击分类直接浏览服务；需求问卷保留独立入口，无问卷分类显示“查看服务”。
- 后台模块的无效删除操作替换为实际启用、停用操作，二次确认说明展示影响；只有接口成功后提示成功，并显示模块状态。未删除模块和产品数据。

## 验证

- 后台 Vue 类型检查与构建通过；小程序 Vue 类型检查、微信构建、H5 构建通过。
- Playwright 使用 H5 构建及模拟接口验证套餐入口跳转、加载失败可见、重试后恢复购买入口。
- Playwright 使用后台构建及模拟接口验证保存失败不显示成功，以及保存成功提交停用状态并提示结果。
- 微信开发目录已通过热编译更新。浏览器验证不替代微信真机支付、资格审批及咨询详情完整业务验收。
- 未进行生产下架、模块停用、支付或退款操作。
