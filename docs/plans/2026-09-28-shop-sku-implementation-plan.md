# 商城 SKU 实施计划

**状态：** 代码、应用构建及临时隔离库迁移回填验证通过；未在共享或生产环境应用。

**目标：** 为现有平台自营商品增加可交易的 SKU 规格、独立价格/库存及跨端管理和选择能力。

**架构：** 新增 `ShopProductSku` 作为库存和价格事实来源。购物车、订单行引用 SKU；订单行同步保存不可变商品/SKU 展示快照。旧客户端仅对单 SKU 商品保留兼容。

**技术栈：** NestJS、Prisma、PostgreSQL、Vue 3/Element Plus、UniApp/Vue 3、Jest。

**设计依据：** `docs/plans/2026-09-28-shop-sku-design.md`

## 任务

### 1. 数据模型和迁移

- 新增 SKU 模型和关系、购物车 `skuId`、订单 SKU 快照字段。
- 迁移按旧商品数据回填默认 SKU，再回填购物车及订单；不重置数据库。
- 迁移 SQL 在隔离 schema 验证，不迁移共享/生产库。

### 2. API 商品管理和读取

- 商品创建/更新使用 `skus[]`；每个商品至少一个 SKU，拒绝重复 SKU 编码和重复属性组合。
- 商品详情返回全部可售 SKU；列表价格与库存为 SKU 汇总展示值。
- 已被订单引用的 SKU 不可删除；库存不能降低到低于已预留与已售数量。

### 3. 购物车与订单库存

- 购物车按 SKU 增删改，旧 `productId` 仅在唯一 SKU 时兼容。
- 下单按稳定 SKU ID 顺序锁定、服务端核价、预留 SKU 库存并保存快照。
- 支付、关单和退款库存迁移到 SKU 库存字段。

### 4. 管理端和小程序

- 管理端提供可增删的 SKU 行编辑器和 SKU 级价格/库存/启用状态。
- 小程序商品详情选择规格；购物车、结算按 SKU 显示选项和价格。
- 订单详情显示下单时 SKU 快照。

### 5. 验证与文档

- 补单元测试覆盖 SKU 校验、库存隔离、旧请求兼容和快照。
- 运行商城 mock 单测、API/Admin/小程序类型检查与构建、Prisma validate。
- 更新现行商城设计和数据库文档，记录隔离迁移结果及未执行的数据库范围。

**执行约束：** 保留现有未提交支付/退款改动；不开启支付，不调用微信商户 API，不执行默认本地业务库或生产库迁移，不提交 Git commit。
